## Method

- Corpus: the live shepherd ledger (`shepherd_ledger.jsonl`, 2,680 rows at
  measurement time). Action values found in the ledger: checked,
  closed_unmerged, fix_attempt, merge_conflicts, merged, merged_by_shepherd,
  needs_alex, needs_operator, rerun, snapshot, trigger_requested, other.
- Two sample variants of the 40 most recent terminal dispositions were
  measured, because `needs_alex`/`needs_operator` rows repeat per cycle for
  the same PR and dominate a naive window:
  - `issue_terminal_set`: the issue's terminal set (closed_unmerged,
    merge_conflicts, merged, merged_by_shepherd, needs_operator), window
    2026-11-23T12:22:40Z to 2026-11-25T19:54:02Z.
  - `distinct_pr_terminal_set`: one row per distinct PR (adds needs_alex),
    window 2026-11-20T05:23:10Z to 2026-11-25T19:54:02Z.
- Reconstruction used as-of filtering (`completed_at <= ledger_ts`) via
  read-only `gh` calls; 174 gh calls total including probes (127 and 125
  calls attributed to the two 40-row samples).
